# OSD timing and program EPG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the player OSD use a six-second normal timeout, a one-minute hidden-OSD `OK` timeout, and the actual scheduled programme title and progress where free XMLTV data is available.

**Architecture:** An XMLTV repository downloads and caches the public compressed EPG feed, streams it into an in-memory index only for known channel IDs, and returns the programme active at a supplied instant. The player starts streaming with existing metadata, then updates a ready state asynchronously only when native metadata has no programme interval. The overlay gets its progress from programme timestamps and its visibility duration from the triggering remote command.

**Tech Stack:** Kotlin, coroutines, JUnit 4, OkHttp 5, streaming SAX XML parsing, Jetpack Compose, Media3, Android Gradle Plugin.

**Files:**

- [ ] **Step 1: Write failing cache and lookup tests.**

  Use a `TemporaryFolder` and an injected `suspend () -> ByteArray` downloader. Cover these cases:

  ```kotlin
  @get:Rule
  val temporaryFolder = TemporaryFolder()

  private val nowMs = 1_786_896_300_000L

  private fun repository(
      cacheFile: File = File(temporaryFolder.root, "epg-cz.xml.gz"),
      downloader: suspend () -> ByteArray,
  ) = CachedXmltvEpgRepository(
      cacheFile = cacheFile,
      download = downloader,
      clockMs = { nowMs },
      parser = XmltvEpgParser(),
  )

  private fun xml(channel: String, start: String, stop: String, title: String) =
      """<tv><programme channel="$channel" start="20260816$start" stop="20260816$stop"><title>$title</title></programme></tv>"""

  private fun gzip(xml: String): ByteArray = ByteArrayOutputStream().use { output ->
      GZIPOutputStream(output).use { it.write(xml.encodeToByteArray()) }
      output.toByteArray()
  }

  @Test
  fun `returns programme containing the supplied instant`() = runTest {
      val repository = repository(
          downloader = { gzip(xml("JEDNOTKA.cz", "180000 +0200", "190000 +0200", "Správy")) },
      )
      assertEquals("Správy", repository.currentProgram(TvChannel.JEDNOTKA, 1_786_896_300_000L)?.title)
  }

  @Test
  fun `uses fresh cached feed without downloading again`() = runTest {
      val cacheFile = File(temporaryFolder.root, "epg-cz.xml.gz")
      cacheFile.writeBytes(gzip(xml("JEDNOTKA.cz", "180000 +0200", "190000 +0200", "Cache")))
      cacheFile.setLastModified(nowMs)
      val repository = repository(cacheFile = cacheFile, downloader = { error("download must not run") })
      assertEquals("Cache", repository.currentProgram(TvChannel.JEDNOTKA, nowMs)?.title)
  }

  @Test
  fun `uses last parsed cache when stale refresh fails`() = runTest {
      val cacheFile = File(temporaryFolder.root, "epg-cz.xml.gz")
      cacheFile.writeBytes(gzip(xml("JEDNOTKA.cz", "180000 +0200", "190000 +0200", "Cache")))
      cacheFile.setLastModified(nowMs - 6 * 60 * 60 * 1_000L - 1L)
      val repository = repository(cacheFile = cacheFile, downloader = { throw IOException("offline") })
      assertEquals("Cache", repository.currentProgram(TvChannel.JEDNOTKA, nowMs)?.title)
  }

  @Test
  fun `returns null for unmapped channel without downloading`() = runTest {
      var calls = 0
      val repository = repository(downloader = { calls += 1; byteArrayOf() })
      assertNull(repository.currentProgram(TvChannel.WATERBEAR, nowMs))
      assertEquals(0, calls)
  }
  ```

  Add tests that a malformed download does not replace a valid cache and that an interval boundary selects the programme starting at the boundary, not the one ending there.

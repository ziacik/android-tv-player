# Uptodown publishing assets

This directory contains the material prepared for the Kanálik Uptodown listing.

## Ready to upload

- `icon-512.png` — 512×512 store icon
- `feature-1024x500.png` — exact Uptodown featured-image size
- `short-description.txt` — under 70 characters
- `full-description-en.txt` — English store description
- `changelog-0.1.0.txt` — initial release notes
- `metadata.yml` — package/version/category and console values
- `organization-bio-en.txt` — optional public developer profile bio

## Screenshots

Uptodown recommends at least four screenshots showing the real current UI. They are intentionally not fabricated here. Capture them from a TV/device with `sh capture-store-screenshot.sh <name>` after navigating to a representative screen.

Suggested set:

1. `01-live-osd.png` — live playback with OSD and programme information
2. `02-mini-epg.png` — mini EPG open
3. `03-channel-list.png` — channel list / navigation
4. `04-system-epg.png` — Android TV programme guide integration, if available on the test TV

For an Android TV app, landscape screenshots are representative of the actual product even though Uptodown's generic Android ASO guide primarily recommends portrait images for phone apps.
